# Agent Note: 模型选择的传输失败恢复

[English](2026-10-27-model-directory-transport.md) | 中文

Status: proposed

## 问题

模型目录和模型切换 RPC 被拒绝时，共享目录一直停在加载或切换状态，思考能力可能无法出现，切换错误也没有写入界面状态。

## 方案

在原有目录状态中记录传输失败，保留已经接受的数据，沿用成功响应的代次和销毁检查。不改变模型能力、协议或权限，不自动重发请求。

## 验收

客户端插件组合测试应覆盖目录和切换的错误显示、思考数据保留及显式重试。组件和 Host 回归继续验证关闭思考和档位选择。
