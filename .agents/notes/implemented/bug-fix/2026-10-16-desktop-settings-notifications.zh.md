# Agent Note：桌面通知使用设置分区

状态：已实施

[English](2026-10-16-desktop-settings-notifications.md) | 中文

## 决策

通过设置通知 outlet 传递 `openSection`。能力中心消费通知标记并导航到外壳持有的分区，不持有第二张弹窗。只有未跳过的新版本触发自动导航；持久化操作结果仍可查看，但不抢焦点。组件当前状态与最近一次已确认插件更新记录分开。预发布默认关闭；旧版隐式开启的通道会重置一次，之后用户的主动选择会保留。桌面导航将 MoE4All 放在插件和能力中心之前。

原生执行层负责完全未配置本地引擎的一次性下载。外部地址、已有可执行文件、已安装版本和运行中的引擎不会被接管；协调器不启动推理、不下载模型。原生窗口保存普通尺寸和最大化状态，忽略最小化，并将恢复位置限制在可用显示区域。

## 验证

定向客户端组合测试覆盖导航、持久结果、跳过版本、明确下载与重启确认，以及同配色异步文件选择器。核心测试覆盖首次安装资格、外部服务保护和通道迁移。原生窗口状态 fixture 覆盖尺寸往返及显示区域限制。这些检查不等同于推理或最终发行 ZIP 验收。
