# Agent Note：能力中心区分操作、清单与记录

状态：已实施

[English](2026-10-16-capabilities-action-views.md) | 中文

## 决策

能力中心保留在设置内，提供操作摘要、明确的手动检查入口，以及「全部」「待处理」「更新记录」视图。卡片保留组件简介与绑定版本的操作。跳过版本仍能手动安装，但不增加待处理数量。准备阶段标明当前工作，待应用变更仍需确认重启。回退展示实际恢复目标，不使用最新发布版本。

检查与安装使用不同的失败状态及重试操作。Agent 下载重试保留已确认版本的绑定。托管引擎运行时不隐藏可用更新，但停止该引擎前禁用安装。改变更新设置只刷新元数据。记录为每个插件保留最近一次已确认更新或回退，不伪装成完整审计日志，也不使用无限期完成状态。

## 验证

客户端组合测试覆盖待处理筛选、跳过、记录、检查重试、同版本 Agent 重试、回退目标和运行中引擎限制。原生执行层再次校验命令并持有事务；浏览器不切换运行时文件。布局使用已有控件与语义配色，按内容区宽度切换为单列，文案由语言服务持有。
